# matplotlibのplot

## フォーマット文字列（color/marker/linestyle）

`ax.plot(x, y, "bo-")`のように、`plot()`の第3引数に短い文字列を渡すと、
色（color）・マーカー（marker）・線種（linestyle）をまとめて指定できる。

```python
ax1.plot(list(k_range), inertias, "bo-")
# 以下と同じ意味
ax1.plot(list(k_range), inertias, color="b", marker="o", linestyle="-")
```

文字列中の各文字は「色1文字 + マーカー1文字 + 線種記号」の組み合わせで、順不同かつ省略可能。

### 色（color）

| 文字 | 色 |
| --- | --- |
| `b` | blue（青） |
| `g` | green（緑） |
| `r` | red（赤） |
| `c` | cyan（シアン） |
| `m` | magenta（マゼンタ） |
| `y` | yellow（黄） |
| `k` | black（黒） |
| `w` | white（白） |

### マーカー（marker）

| 文字 | 形状 |
| --- | --- |
| `o` | 円 |
| `s` | 四角 |
| `^` | 三角（上向き） |
| `.` | 点 |
| `x` | バツ |
| `+` | プラス |
| `d` | ダイヤ |

### 線種（linestyle）

| 記号 | 種類 |
| --- | --- |
| `-` | 実線 |
| `--` | 破線 |
| `-.` | 一点鎖線 |
| `:` | 点線 |

### 組み合わせ例

- `"bo-"`: 青、丸マーカー、実線
- `"ro--"`: 赤、丸マーカー、破線
- `"g^:"`: 緑、三角マーカー、点線
- `"k."`: 黒、点マーカーのみ（線なし）

マーカーを省略すると線のみ、線種を省略するとマーカーのみ（線なし）になる。
