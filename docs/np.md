# NumPy

## `np.linspace`

指定した範囲を、指定した個数の点で**等間隔に**分割した配列を作る。

```python
np.linspace(0, 115_000, 1000)
# 0 から 115,000 までを、1000個の等間隔な点で埋めた1次元配列
# array([0., 115.115..., 230.230..., ..., 115000.])
```

| 引数 | 意味 |
| --- | --- |
| `start` | 開始値（デフォルトで含む） |
| `stop` | 終了値（デフォルトで含む。`endpoint=False`で除外可） |
| `num` | 生成する点の個数（デフォルト50） |

主な用途は、学習済みモデルの**予測曲線を滑らかに描く**こと。実データの点（`X`）はまばらなので、
そのまま`plt.plot(X, y_pred)`すると折れ線がカクカクになる。そこで`X`の範囲をカバーする
密な点列を`linspace`で作り、それをモデルに`predict`させてから描画する。

```python
X_line = np.linspace(0, 115_000, 1000).reshape(-1, 1)
plt.plot(X_line, reg.predict(X_line), label="prediction")
```

似た関数に`np.arange(start, stop, step)`があるが、`arange`は**間隔（step）**を指定するのに対し、
`linspace`は**個数（num）**を指定する点が違う。「何点で描きたいか」が先に決まっている場合は
`linspace`の方が扱いやすい。

## `.reshape`

配列の要素数はそのままに、**形状（次元）だけ**を変える。

```python
a = np.linspace(0, 115_000, 1000)  # shape: (1000,)  1次元配列
a.reshape(-1, 1)                    # shape: (1000, 1)  2次元配列（1000行1列）
```

### なぜ`reshape(-1, 1)`が必要か

scikit-learnの`fit`/`predict`は、特徴量`X`を**2次元配列（`(サンプル数, 特徴量数)`）**として要求する。
`np.linspace`が返すのは1次元配列なので、そのまま`predict`に渡すとエラーになる。
`reshape(-1, 1)`で「列数1・行数は自動計算」の2次元配列に変換してから渡す。

| 引数 | 意味 |
| --- | --- |
| `-1` | この軸のサイズは、他の軸から自動計算する（「よしなにやって」の意） |
| `1` | 列数を1に固定する |

`reshape(-1, 1)`（1列の縦ベクトル化）と`reshape(1, -1)`（1行の横ベクトル化）は用途が違うので混同しないよう注意。
`-1`は複数の軸に同時には使えない（サイズが一意に決まらないため）。
