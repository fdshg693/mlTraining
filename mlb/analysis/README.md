# analysis

`data_produce/` が取得したデータの分析・可視化を行うモジュール群。

## フォルダ分けの基準

分析の種類（何を明らかにするCLIか）ごとにサブフォルダを分ける。1サブフォルダ = 1つの分析観点のCLIスクリプト。現在は以下の4つ。

- `overview/`: 単一フィールドの分布・ランキングを見る
- `correlation/`: 2フィールド間の相関関係を見る
- `prediction/`: 2フィールド間で単回帰による予測を行う
- `role/`: 投手を先発/リリーフに分類して比較する
- `clustering/`: 複数フィールドで投手をクラスタリング・外れ値検出する（教師なし学習）

新しい分析観点を追加する場合、既存フォルダのどれにも当てはまらなければ新しいサブフォルダを切る。

## スクリプトの実行方法

各スクリプトの実行コマンドと概要は [COMMANDS.md](COMMANDS.md) を参照。引数の詳細やアルゴリズムの意図は各スクリプトファイルのdocstringを参照。
